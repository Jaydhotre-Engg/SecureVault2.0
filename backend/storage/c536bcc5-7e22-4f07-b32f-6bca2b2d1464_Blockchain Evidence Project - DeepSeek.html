4. Your Architecture — Three Layers

Layer 1 — Blockchain (Source of Truth)

  • Ethereum Sepolia testnet

  • Solidity smart contracts store: evidence hash, IPFS CID, uploader, timestamp, CoC events

  • Never stores actual files (too expensive)

Layer 2 — AI (Derived Artifacts Only)

  • Local LLM (Ollama / Llama 3.2 / Qwen / Mistral)

  • Generates: case summaries, draft reports

  • Never writes to blockchain directly

  • Never modifies evidence

Layer 3 — Human Review (Mandatory Gate)

  • Officer reviews AI draft → edits → approves/rejects

  • Only approved reports are hashed + anchored on-chain

  • Every AI output is a draft, not a final product

Golden rule: AI can read from blockchain for context, but can never write to it. Only human-reviewed artifacts get anchored.
